# BiasBuster – AI Gender Bias Detection

BiasBuster is an AI-based system designed to detect gender bias in recruitment texts.

## Technologies
Python
Machine Learning
Natural Language Processing

## Features
- Detects biased recruitment language
- Helps promote fair hiring practices
- Supports gender equality initiatives
